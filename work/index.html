Case study

The Momentum Scanner.

A live trading scanner running every weekday, built from scratch with no prior coding experience, on £0 infrastructure. Here's the problem it solves, how it's built, and what building it actually took.

01

The project

Active · Daily · Free to run

Momentum
Scanner

Python yfinance Pandas Streamlit GitHub Actions Altair Streamlit Cloud

The problem

US stocks that gap up in premarket with above-average volume tend to continue moving in the first 15 minutes of regular trading. Identifying which ones are worth acting on — before the market opens — requires scanning hundreds of tickers, scoring them across multiple signals, and having that information ready by 13:30 BST. Doing it manually every day is not realistic.

Started

May 2026 — 72 hours from idea to first live deployment, with no prior coding experience and £0 infrastructure cost, entirely on free tiers.

What it does

  • Runs automatically every weekday at 13:00 BST via GitHub Actions
  • Scores 250+ US stocks across five momentum signals
  • Publishes results to a live Streamlit dashboard before the NYSE opens
  • Pre-trade confirmation check at 14:00 BST re-scores top candidates live
  • 14-day backtest with 1-minute candle replay and trade simulation
  • Premarket momentum assessment flags the Hub Cyber Security pattern

The scoring model

Score = (3 × gap%) + (2 × RVOL) + (0.5 × trend) + (2 × breakout) + (1 × volatility). Stocks scoring above 9 with a live premarket gap are the primary trade candidates.

Any trading figures shown on the live dashboard are practice-account results, not real income.

How it works

01

Scheduled pipeline

GitHub Actions triggers universe.py at 12:00 UTC (13:00 BST) Monday to Friday. No manual intervention required.

→
02

Data retrieval

yfinance pulls 15 days of OHLCV data plus live premarket price and volume for each ticker in the watchlist.

→
03

Scoring & ranking

Five signals computed per ticker. Weighted score calculated. Results written to output/universe.csv and committed back to the repo.

→
04

Live dashboard

Streamlit Cloud reads the CSV directly from GitHub. Dashboard updates automatically. No server to manage.

Why this matters

"I've always had a million ideas. ADHD makes them arrive all at once, loud, and rarely in order. For years the gap wasn't ideas, it was turning them into something real. Learning to build closed that gap."

This project isn't a tutorial I followed. It isn't a Kaggle notebook. It's something I built from nothing because I had an idea and wanted to know if I could make it work.

I'm a performance marketer. My day job is making advertising systems perform better. What I've discovered is that the skills behind that — structured thinking, data interpretation, identifying signals in noise, knowing when to act and when to wait — transfer directly into building data-driven automation systems.

The AI tools I used accelerated my learning. They didn't replace the decision-making. Every design choice in this system, every fix when something broke, every time the backtest showed a result that didn't make sense and I had to figure out why — that was me.

This sits alongside my other AI projects, such as Wade, the website automation team and the Research Lab. See AI & Agents for those.

Also built: AI Job Finder

"Decide what a good role looks like for you first. Then let AI do the searching."

A free, open toolkit I built to help people in my network who've been made redundant, and shared for anyone who has lost their job or wants a change. You build a personal scoring rubric with AI, then AI searches the web for roles and scores each one against it, so you only spend time on the roles that fit.

It comes at three levels: a single copy-and-paste prompt for complete beginners, a reusable project you run each week, and a GitHub template that runs every Monday on GitHub Actions, scores new roles with Claude, keeps a tracker and emails a shortlist.
