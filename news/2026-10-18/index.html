Google drops ad vendor it listed since 2020 after 45-device spyware attack

PPC Land · 2026-10-18

Google and IAB Europe pulled Israeli ad company Discover‑Tech from their vendor lists after a Citizen Lab investigation revealed that the firm’s ads were used to deliver Candiru spyware to at least 45 Al Jazeera devices without any user interaction. The report, titled "Exposing AdFection," shows how targeted ads could trigger malware simply by being displayed, using real‑time bidding data and embedded JavaScript. Discover‑Tech had been an approved vendor for almost six years, so its malicious code reached tens of thousands of apps and sites. Researchers now urge regulators to investigate and the ad industry to scrutinise partners more closely.

  • Discovery that zero‑click ads can deliver spyware (AdFection) to devices without user action
  • Google, IAB Europe and several ad platforms removed Discover‑Tech after Citizen Lab’s findings involving Al Jazeera devices
  • Researchers call for regulatory investigation and tighter vetting of advertising partners

Google’s Indexing API Docs No Longer Explain How To Get Approval via @sejournal, @MattGSouthern

Search Engine Journal · 2026-10-17

On 16 October Google deleted the Indexing API approval form and all related guidance from its documentation. Developers still see a default limit of 200 publish requests per day (both updates and removals) and per‑minute caps of 180 metadata calls and 380 total endpoint calls, resetting at midnight Pacific Time. The API remains restricted to pages containing JobPosting or BroadcastEvent inside a VideoObject, and Google’s spam policies still apply. No timelines or procedures are now provided for reviewing pending approval requests.

  • Google removed the Indexing API approval form and all instructions on how to request approval from its docs;
  • The quota page now lists only current limits—200 daily publish requests, 180 per‑minute metadata calls, 380 per‑minute total calls—without any guidance on requesting higher quotas;

Meta removes language that may have allowed it to scrape news sites

The Verge AI · 2026-10-17

Meta has updated its commercial terms, removing a clause that could have allowed the company to scrape content from news sites for AI training. The deleted language stated Meta might use any content from domains, webpages or URLs to develop and improve its products, services and features. Critics argued this gave Meta rights to bypass site owners’ robots.txt instructions. In response, Meta’s communications team said the change does not alter how web crawlers are used; it only clarifies that the earlier terms applied to ads and business products and respects content owners’ preferences.

  • Meta removed a clause from its commercial terms that could have permitted scraping news sites for AI training.
  • The clause allowed Meta to use any domain’s content to develop its products, which critics said bypassed robots.txt rules.
  • Meta states the update does not change crawler behaviour; it merely clarifies that the earlier language applied only to ads and business products.

Websites are closing their doors to AI agents

The Verge AI · 2026-10-17

Major web services are increasingly refusing to allow autonomous AI agents to operate on their platforms. Yelp only permits licensed agents, Delta blocks ticket‑booking bots, and banks like JPMorgan Chase and Charles Schwab deny account access for security reasons. Amazon previously banned Perplexity’s shopping agent, sued the startup, and later had a court order overturned before filing an amended complaint. OpenAI, Meta and Google agents such as Muse, Grok, Instinct and Dots are also encountering similar roadblocks, though some firms have partnered with retailers like Walmart or Gap to enable limited access. Cloudflare’s 2025 one‑click AI crawler block further hampers bots that scrape sites for both search indexing and training data.

  • Websites such as Yelp, Delta, banks, Amazon and others are actively blocking or restricting AI agents due to licensing, security or advertising concerns.
  • Leading AI firms’ agents (OpenAI, Meta, Google) face legal disputes and operational hurdles, yet some have formed partnerships with specific retailers to allow limited use.
  • Cloudflare’s one‑click block for AI crawlers and widespread anti‑bot systems add additional barriers that can trigger false positives and make web interactions more cumbersome.

Asynchronous Tasks With Django and Celery

Real Python · 2026-10-18

Celery is a distributed task queue that lets you run time‑consuming work outside the main request thread, keeping a Django app responsive. Finally it lists common web‑app use cases – email, image and text processing, API calls, data analysis, ML runs and report generation – where offloading to Celery improves performance.

Digging Deeper Into Django Migrations

Real Python · 2026-10-18

The article explains how Django manages migrations after you create and apply them, focusing on the django_migrations table that records each applied migration so it won’t run again unless its row is removed. It describes what a migration file looks like – a Python class inheriting from django.db.migrations.Migration with an operations list (e.g., CreateModel) and optional dependencies. Operations generate SQL for the database, and while Django supplies many built‑in ones you can also write custom operation classes or use PostgreSQL‑specific ops. The piece cautions that automatic detection may misinterpret complex changes, so reviewing generated migrations before production is advised.

  • Django records applied migrations in the django_migrations table to prevent re‑applying them
  • A migration file is a Python class with an operations list and dependencies that generate SQL for the database
  • You can extend migrations with custom operation classes or PostgreSQL‑specific ops, but automatic detection may misinterpret complex changes

DeepSeek search and fetch – $0.75 per 1000 successful requests

Hacker News best · 2026-10-18

DeepSeek offers two read‑only JSON APIs – Search and Fetch – that let agents pull live web data. Both use bearer auth, require a JSON body, and return HTTP 200 on success. A Search request includes a query string (operators accepted), count of results, and an optional need_content flag; the response contains an array of result objects with title, url, snippet, summary, content, etc., or an empty array if nothing matches. Fetch takes a URL and returns a page’s title and Markdown‑formatted content; errors are returned in OpenAI‑compatible JSON. Billing is per successful request only (non‑empty Search results or fetched content); failed or empty responses aren’t charged. QPS limits apply separately to each API, with an additional per‑domain limit for Fetch.

  • Search returns a JSON array of result objects and is billed only when the array is non‑empty; Fetch returns page title and Markdown content and is billed only when content is retrieved
  • Both APIs use bearer authentication, accept JSON bodies, return HTTP 200 on success, and follow OpenAI‑compatible error formatting

DeepSeek: DeepSeek v4.1 Flash 1017

Hacker News best · 2026-10-17

DeepSeek V4.1 Flash 1017, released on 17 Oct 2026, is a sparse mixture‑of‑experts model built on DeepSeek’s Causal Encoder‑Decoder (CED) architecture. It activates 8 B parameters for input and 16 B for output from a 552 B backbone, keeping per‑token compute low while offering a 1,048,576‑token context window. The model natively handles images and text, with visual and textual embeddings trained jointly from pre‑training, making it ideal for coding, terminal, computer‑use agents and long‑horizon tasks. KV caching is compressed to about one‑quarter of the previous Flash generation, cutting agentic workload costs. Pricing is $0.05 / M input tokens, $0.60 / M output tokens, with cache read at $0.008 / M tokens, and it supports tools, function calling and structured JSON outputs.

  • Sparse mixture‑of‑experts CED architecture with 8B input / 16B output activation from a 552B backbone and 1,048,576‑token context window
  • Native multimodal support: text and images trained jointly, suited for coding, terminal and long‑horizon agent tasks
  • Cost‑efficient tier: compressed KV caching reduces memory use; pricing $0.05/M input, $0.60/M output, $0.008/M cache read
