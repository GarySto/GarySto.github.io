Google's DV360 API v5 can now create responsive YouTube ads

PPC Land · 2026-11-14

Google added the ability to create, update and delete responsive YouTube ads to version 5 of the Display & Video 360 API. The change covers four kinds of YouTube‑and‑partners line items – efficient reach, non‑skippable reach, target frequency and video views – but leaves instant deal buying and single‑format YouTube ads outside the API. Line items and ad groups must still be built in the DV360 interface or via Structured Data File uploads. The responsive ads can serve in‑stream, Shorts and in‑feed placements; their creative assets are managed through the advertisers.adAssets service. Version 5 remains public beta and may receive breaking changes.

  • API v5 now supports CRUD for responsive YouTube ads across four line‑item types while still requiring line items/ad groups to be created via DV360 UI or SDF
  • Responsive ads can serve in‑stream, Shorts and in‑feed formats, with creative assets handled by the adAssets service
  • Version 5 is public beta; Google may make breaking changes before finalisation

Google Ads Updates Conversion Lift Set Up Documentation

Search Engine Roundtable · 2026-11-13

Google Ads has updated its Conversion Lift setup documentation to tighten measurement requirements rather than change the study mechanics. Key changes include more detailed rules for Enhanced Conversions (hashed customer data such as emails, phone numbers and addresses), a clarification that GCLID‑only imports are insufficient for offline conversions, and explicit identification of unsupported configurations like GA4‑imported web conversions. The update also adds guidance on Consent Mode, app conversion integrations, and data quality – recommending 7–14 days of continuous conversion data, valid currencies, dynamic values, and routing roughly 75–80 % of web traffic through the Google tag gateway. Advertisers are urged to audit their tracking before launching a study.

  • Enhanced conversions now require detailed hashed customer data; offline conversions need more than GCLID‑only imports.
  • Certain setups such as GA4‑imported web conversions are explicitly unsupported for Conversion Lift studies.
  • Data quality guidelines emphasise 7–14 days of continuous conversion data, valid currencies, dynamic values and routing most traffic through the Google tag gateway.

Search Engine Journal · 2026-11-13

Google has updated its Target Frequency help page to allow advertisers to mix non‑skippable in‑stream ads (up to 20 s) with Shorts and in‑feed ads within the same campaign, a change from an earlier rule that prohibited such combinations. Google Analytics Data Manager: duplicate Ads setups can log conversions twice

PPC Land · 2026-11-08

Managing Multiple Python Versions With pyenv

Real Python · 2026-11-07

Pyenv is a command‑line tool that lets developers install and switch between multiple Python versions without touching the operating system’s default interpreter, preventing version conflicts and keeping the OS clean. The article explains why using the system Python can break OS components or lock you into old releases, especially when global packages clash across projects. To use pyenv you first need to install build dependencies that vary by Linux distribution (Ubuntu/Debian, Fedora, openSUSE) or macOS via Homebrew. After installing these prerequisites, you run an automatic installer script and then set up your shell environment so pyenv can manage versions and create virtual environments.

  • Pyenv allows multiple Python installations without affecting the system interpreter, avoiding OS conflicts.
  • Installing pyenv requires first adding platform‑specific build dependencies before running the installer.
  • Once installed, you must configure your shell for pyenv; plugins can extend its core functionality.
